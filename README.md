# Linux C 文件服务器实验

早期使用 C 语言尝试实现的客户端/服务端文件传输程序。当前内容集中在 [`1_file_server`](./1_file_server)：

- [client](./1_file_server/client)：命令行客户端，包含查看列表、上传等交互。
- [server](./1_file_server/server)：基于 TCP 与 `epoll` 的服务端代码。
- 仓库中也保留了当时的可执行文件和编译生成文件。

## 项目状态与注意事项

**历史学习原型，尚未完成，不适合部署到公网或用于生产。**

源码中存在固定内网地址、输入长度处理、文件路径拼接等需要修正之处；下载功能也未完整实现。保留仓库主要用于回顾网络编程、事件驱动和多线程文件传输的学习过程。

未来如重启项目，建议先补齐输入校验、路径隔离、访问控制和测试，再提供可运行版本。
