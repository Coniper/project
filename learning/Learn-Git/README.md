# 当时练 Git 用的仓库

这里没有完整的教程，主要是我 2022 年练提交、分支和标签时留下的占位文件。很多文件是空的，本来就是拿来观察 Git 行为的。

原仓库有 `main`、`dev`、`test` 三个分支，以及 `v1.0` 标签。为了以后翻阅时不漏掉内容，我把当时各个分支、标签指向的文件也放到了 [snapshots](./snapshots)：

- [dev](./snapshots/dev)：多了一个 `new.c`；
- [test](./snapshots/test)：只有 `A` 到 `G` 这几个占位文件；
- [v1.0](./snapshots/v1.0)：当时打标签的文件快照，包含 `new.c` 和 `test.c`。

这只是**文件快照**，不等于把原来的 Git 提交关系和标签对象一起迁过来了。完整历史还得用 Git 另外备份。
