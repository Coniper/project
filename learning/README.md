# 学习代码，集中放在这里

原来一个知识点开一个仓库，找代码挺费事。我把以前那些 C、Linux 和 Git 练习复制到了这个目录，文件名、目录层次基本没动，免得旧笔记里的位置全对不上。

从 C 语言基础题开始，后面依次有文件 I/O、进程、线程、动态库、Socket 和 SQLite3。这个顺序差不多也能看出我当时在学什么。单独的文件服务器练习还放在[仓库根目录的 1_file_server](../1_file_server)。

我没有整理成完整教程，文件里的错误、旧写法也可能还在。想查哪段代码就点进去看；真要拿去用，先自己编译、测试，尤其是网络相关的例子。

原仓库还在，保留原来的提交历史。这里是方便翻阅的一份集中副本。编译产物和 `SQLite3` 的旧数据库文件没有重复复制。
