# 学习代码，集中放在这里

以前一个知识点就建一个仓库。2021 年学 C、Linux 时这样做还挺方便，几年后再找代码反倒要挨个翻。这次干脆把它们集中到这里，旧的目录和文件名基本都没改。

按内容翻就行：[C](./C)、[IO](./IO)、[Process](./Process)、[Thread](./Thread)、[make-lib](./make-lib)、[Socket](./Socket)、[SQLite3](./SQLite3)、[Learn-Git](./Learn-Git)。当时做的[文件服务器](../1_file_server)仍在上一层目录。

这些是我的练习稿，不是准备直接交付的程序。有些写法现在看应该改，尤其网络程序的输入处理和文件路径相关部分，别拿来直接部署到公网。

代码和可读取的笔记已经集中。二进制编译文件、SQLite 的旧数据库还留在原仓库；`Learn-Git` 额外补了旧分支和标签的[文件快照](./Learn-Git/snapshots)。**原始提交历史还没有迁入这里**，所以旧仓库暂时不能当作完全备份成功后直接删除。
